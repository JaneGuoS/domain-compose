Key Workflows
Add File
POST /teamSites/{id}/files → FileWriter (bypasses domain) → IFileOrchestrator (business logic here) → IFileRepository.AddFile() → Kafka → content-event → Kafka → search.ingest
Publish Content
POST /publish → IPublishOrchestrator (status logic inline) → ItemModel.Status = "published" (no invariant) → Repository.UpdateAsync() → Kafka → content-event (Published) → NotificationService
External Content Sync (Google Drive / OneDrive)
POST /externalSync → ExternalSyncService.SyncAsync() → IContentSyncClient (Google / OneDrive) → IExternalSyncOrchestrator → IExternalSyncRepository.CreateTaskAsync() → SyncIndicatorBGService (polling)
Document Processing Pipeline (CCP → AI Augmentation)
Kafka ← eventbus.public.ccp.meta → CrackingPipelineMetaEventListener → AugmentationEventListener → AI/ML Augmentation → COSClientProvider → Kafka → content-event (Processed)
Virus Scan & Security Quarantine
Kafka ← blob-virus-scan.audit-trail → VirusScanEventListener → IExpirationOrchestrator (quarantine logic) → Repository.UpdateStatusAsync() → NotificationService (alert owner)
Schedule Publish
POST /schedulePublish → ILightSchduleJobOrchestrator → IItemRepository.CreateScheduleAsync() → RLPollingBackgroundService (timer) → IPublishOrchestrator.ExecuteAsync() → Kafka → content-event (Published)
